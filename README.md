# university-library-management-system.-
A software solution to streamline and automate university library operations.


Welcome to the **University Library Management System** repository! This project is designed to automate daily library operations, making it efficient for students, faculty, and library administrators to manage books, borrowing records, and inventory.

---

## 📌 Project Scope & Objectives

### **In-Scope**
* **User Authentication & Roles:** Student, Faculty, and Admin access levels.
* **Book Inventory:** Add, update, search, and organize books by title, author, and ISBN.
* **Circulation Management:** Issue/return tracking, due dates, and fine calculations.

### **Out-of-Scope**
* External third-party library integrations.
* Physical hardware setup (RFID/Barcode readers).
